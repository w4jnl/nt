# nt for Mac

The notes repository in a Mac window: the folders beside the note, the note in live preview.
A second client of the same repository; docs/design.md §8 is the spec, and phase 6 lists the
steps, all done and released with 0.5.1 (`brew install --cask w4jnl/tap/nt-app`, or the
notarized DMG on the release). It shows notes in live preview, follows links, saves what is
written in them through nt (`nt _editor save`) as the nvim plugin does, and has the Todos,
Calendar, Weekly and Agents views. It stays in the menu bar, where ⌥⌘Space opens a field that
adds a line to today or a todo from anywhere, and Settings (⌘,) has nt's settings and its own.

macOS keeps ⌥⌘Space for the Finder search window until it is turned off in System Settings ›
Keyboard › Keyboard Shortcuts › Spotlight; Settings › App says so, or records another shortcut.

## Build

Needs Xcode 26 or later, [XcodeGen](https://github.com/yonaskolb/XcodeGen) and Go.

```sh
make mac-run      # build nt for both Mac architectures, generate the project, build, open
make mac-test     # the Swift tests
make mac-editor   # after a change under editor/src: test and rebuild the editor page (Node)
```

`make mac-project` writes an empty `Local.xcconfig`; put your team id in it
(`Local.xcconfig.example`) to sign for other Macs. Without one the app is signed to run on this
Mac only.

The app finds the repository as nt does: `NT_REPO`, else `repo` in `~/.config/nt/config.toml`.
For a look at it without your notes:

```sh
make build && D=$(assets/demo/scene.sh)
NT_CONFIG=$D/config.toml NT_STATE=$D/state NT_REPO=$D/notes \
  app/macos/build/DerivedData/Build/Products/Debug/nt.app/Contents/MacOS/nt -NTAppearance dark
```

## Layout

```
project.yml          the Xcode project, generated by XcodeGen (the .xcodeproj is not committed)
Nt/NtApp.swift       the window, the menu bar item and Settings, and their commands
Nt/Model/            Watcher (FSEvents), Capture (what the panel adds), Shortcut (the capture hot key)
Nt/Views/            the sidebar, the note, Open and Search, the menu bar (and the mark it draws),
                     the capture panel, Settings
../shared/           with the iOS app: Brand (the design system's colours and the brand face),
                     Model/ (Workspace, the app's state; NT, which runs nt; RepoIndex, the
                     sidebar's tree; SyncStatus, Fuzzy, Links, Agenda, Settings), Editor/
                     (NoteEditor: the web view the note is in, saving it, nt-asset: for images)
                     and Views/ (Todos, Calendar, Agents, the folder tree, the sync state)
Nt/Resources/editor  the editor page, built from editor/ and committed; the iOS app has it too
editor/              CodeMirror 6, nt's live preview (src/livepreview.js) and writing (src/edits.js),
                     their tests
NtTests/             Swift Testing; WritingTests drive the editor page and the bundled nt
```

The app bundles `nt` (`make nt-universal`) in `Contents/Helpers/nt`, the editor page and the
design system's fonts. It is not sandboxed: it reads the repository where it is and runs nt,
which takes the repository's locks.

## Releasing

`scripts/release.sh <version>` releases the app with the command line: before it tags, it runs
`scripts/mac-release.sh <version>` (or `make mac-release V=<version>` on its own), which builds
the app in Release with nt stamped with the version, signs both with the team's Developer ID,
has Apple notarize the app and then the DMG, staples both and checks them as Gatekeeper does.
After the tag it adds `nt-<version>.dmg` to the GitHub release and writes the cask
(`brew install --cask w4jnl/tap/nt-app`).

It needs, on the Mac that releases:

- the team's Developer ID Application certificate in the keychain (Xcode › Settings › Accounts ›
  Manage Certificates › + › Developer ID Application; keep a `.p12` backup of it);
- in `Local.xcconfig`: `NT_TEAM_ID`, and the App Store Connect API key that notarizes,
  `NT_ASC_KEY_ID` and `NT_ASC_ISSUER_ID` (a team key with the Developer role), its `.p8` in
  `~/.appstoreconnect/private_keys/`;
- `gh`, to add the DMG to the release.

## Third-party code

The editor page bundles CodeMirror 6 and its parsers, MIT-licensed; their licences are in
`Nt/Resources/editor/LICENSES.txt`, which `make mac-editor` writes. The app has no other
third-party code.
